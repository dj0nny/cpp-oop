---

## Constraints

* Use an abstract base class `Account`
* Create at least three different derived account classes
* Use public inheritance
* Use at least one pure virtual function
* Use `override` in derived classes
* The base class must have a virtual destructor
* Use runtime polymorphism
* Store different account types in a single STL container
* Use `std::unique_ptr` for account ownership
* Use `std::make_unique` to create account objects
* Do not use `std::shared_ptr` or `std::weak_ptr`
* Do not use `new` / `delete`
* Do not use `dynamic_cast` to determine the concrete account type
* Account IDs must be unique and generated by the program
* The account balance must not be directly modifiable from outside the class
* Deposit and withdrawal operations must be controlled by the account
* Different account types must be able to apply different rules to their operations
* Handle invalid operations, such as withdrawals that are not allowed
* Use at least one `enum class` where appropriate
* Use `const` where appropriate
* Use separate header and source files (`.hpp` / `.cpp`)
* Use a command-line menu
* Keep the responsibilities of the classes clearly separated

## Build

The project uses CMake.

```bash
cmake -S . -B build -G "MinGW Makefiles"

cmake --build build
```

Git Bash:

```bash
./build/banking-management.exe
```
