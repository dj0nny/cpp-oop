# Project 02 — Animal Management System

A command-line animal management application written in C++.

---

## Features

The application allows the user to:

* Add a new animal
* Display all animals
* Search for an animal
* Make an animal perform its specific behavior
* Remove an animal
* Exit the application

The application manages different types of animals through a common interface.

Each animal has a unique ID, a name, an age, and a species.

## Requirements

* C++23
* CMake 3.20 or later
* GCC / MinGW

---

## Constraints

* Use an abstract base class `Animal`
* Create at least three different derived animal classes
* Use public inheritance
* Use at least one pure virtual function
* Use `override` in derived classes
* The base class must have a virtual destructor
* Each derived class must implement at least one behavior differently
* Store different animal types in a single STL container
* Use runtime polymorphism
* Do not use `std::variant` to replace polymorphism
* Do not use `dynamic_cast` to determine the concrete animal type
* Do not use smart pointers
* Do not use `new` / `delete`
* Animal IDs must be unique and generated by the program
* Use at least one `enum class` where appropriate
* Use a command-line menu
* Handle attempts to access or modify non-existent animals
* Keep the responsibilities of the classes clearly separated
* Use `const` where appropriate

## Build

The project uses CMake.

```bash
cmake -S . -B build -G "MinGW Makefiles"

cmake --build build
```

Git Bash:

```bash
./build/animal-management.exe
```
