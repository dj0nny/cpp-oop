# Project 04 - Smart Pointer Manager

Ownership-based OOP application.

---

## Features

Main application's features:

* Dynamic memory allocation
* Copy Semantic
* Move Semantic
* Smart pointers

---

## Concepts

This project will practice and combine concepts such as:

* Classes
* Semantics
* Memory Allocation
* RAII
* Smart pointers
* Ownership

---

## Requirements

* C++20
* CMake 3.20 or later
* GCC / MinGW

---

## Build

The project uses CMake.

```bash
cmake -S . -B build -G "MinGW Makefiles"

cmake --build build
```

Git Bash:

```bash
./build/smart-pointer-manager.exe
```
