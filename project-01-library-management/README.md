# Project 01 — Library Management System

A command-line library management application written in C++.

---

## Features

The application allows the user to:

* Add a new book
* Display all books
* Search for a book
* Borrow a book
* Return a book
* Remove a book
* Exit the application

Each book has a unique ID, a title, an author, a publication year, and an availability status.

## Requirements

* C++23
* CMake 3.20 or later
* GCC / MinGW

---

## Constraints

* Use at least two classes
* Class data members must be private
* Use constructors to initialize objects
* Use `const` where appropriate
* Store books using an STL container
* Book IDs must be unique and generated by the program
* Use at least one `enum class`
* Handle attempts to access or modify non-existent books
* Do not use inheritance
* Do not use smart pointers
* Do not use `new` / `delete`
* Use a command-line menu
* Keep the responsibilities of the classes clearly separated

---

## Build

The project uses CMake.

```bash
cmake -S . -B build -G "MinGW Makefiles"

cmake --build build
```

Git Bash:

```bash
./build/library-management.exe
```
