# Project 03 - Dynamic Array

A dynamic array class replica.

---

## Features

Main application's features:

* Dynamic memory allocation
* Copy Semantic
* Move Semantic

---

## Concepts

This project will practice and combine concepts such as:

* Classes
* Semantics
* Memory Allocation
* RAII

---

## Requirements

* C++20
* CMake 3.20 or later
* GCC / MinGW

---

## Build

The project uses CMake.

```bash
cmake -S . -B build -G "MinGW Makefiles"

cmake --build build
```

Git Bash:

```bash
./build/battle-area.exe
```
